# ☕ BaristaAI - Gemini Powered Coffee Business Assistant

BaristaAI adalah aplikasi Chatbot interaktif berbasis Artificial Intelligence untuk ekosistem bisnis kopi. Ditujukan sebagai Final Project Maju Bareng AI (Hacktiv8 x Google.org).

## Fitur Utama
- Multi-Persona (Virtual Barista & Konsultan Bisnis)
- Dynamic Parameter Tuning (Temperature, Model Choice)
- Chat History Memory

## Cara Menjalankan
1. Install dependencies: `pip install -r requirements.txt`
2. Jalankan aplikasi: `streamlit run app.py`
